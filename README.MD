# 개인정보처리방침 / Privacy Policy

## 개인정보처리방침

본 개인정보처리방침은 본 프로그램의 개인정보 처리 방식에 대해 설명합니다.

### 1. 개인정보 수집 여부

본 프로그램의 개발자는 사용자의 개인정보를 수집하지 않습니다.

본 프로그램은 이름, 이메일 주소, 전화번호, 위치 정보, 기기 식별자, 사용 기록, 파일 내용 등 사용자를 식별할 수 있는 어떠한 개인정보도 개발자에게 전송하거나 저장하지 않습니다.

### 2. 데이터 처리 방식

본 프로그램에서 사용되는 모든 데이터는 사용자의 기기 내에서만 처리됩니다.

사용자가 프로그램에서 생성하거나 불러온 데이터는 외부 서버로 전송되지 않으며, 개발자는 해당 데이터에 접근할 수 없습니다.

### 3. 제3자 제공

개발자는 사용자의 개인정보를 수집하지 않으므로, 제3자에게 제공하는 개인정보도 없습니다.

### 4. 외부 서버 및 분석 도구

본 프로그램은 개인정보 수집을 위한 외부 서버, 광고 SDK, 분석 도구, 추적 도구를 사용하지 않습니다.

### 5. 개인정보 보관 및 파기

개발자는 사용자의 개인정보를 수집하거나 보관하지 않으므로, 별도의 개인정보 보관 및 파기 절차가 존재하지 않습니다.

사용자가 프로그램 내에서 저장한 데이터가 있는 경우, 해당 데이터는 사용자의 기기 내에 보관되며 사용자가 직접 삭제할 수 있습니다.

### 6. 문의

본 개인정보처리방침에 대한 문의가 있는 경우, 아래 연락처로 문의할 수 있습니다.

- 이메일: `team@soleil.channel.io`

### 7. 시행일

본 개인정보처리방침은 2026년 5월 5일부터 시행됩니다.

## Privacy Policy

This Privacy Policy explains how this program handles user data.

### 1. Collection of Personal Information

The developer of this program does not collect any personal information from users.

This program does not transmit or store any information that can identify users, including but not limited to names, email addresses, phone numbers, location information, device identifiers, usage history, or file contents.

### 2. Data Processing

All data used by this program is processed locally on the user's device only.

Any data created, loaded, or managed by the user within the program is not transmitted to any external server. The developer cannot access such data.

### 3. Sharing with Third Parties

Because the developer does not collect any personal information, no personal information is shared with third parties.

### 4. External Servers and Analytics Tools

This program does not use external servers, advertising SDKs, analytics tools, or tracking tools for the purpose of collecting personal information.

### 5. Data Retention and Deletion

The developer does not collect or store any personal information, so there is no separate retention or deletion process for personal information.

If the user stores data within the program, that data remains on the user's own device and can be deleted by the user directly.

### 6. Contact

For questions about this Privacy Policy, please contact:

- Email: `team@soleil.channel.io`

### 7. Effective Date

This Privacy Policy is effective as of May 5, 2026.
